Privacy Policy

Laonion Metrics · Last updated: October 19, 2026

Laonion Metrics is a private tool that the owner of the YouTube channel Cogs & Curves runs on their own computer to see the channel's statistics on a personal dashboard. It is not offered to the public: the only user is the channel owner. See the home page for what it does.

YouTube API Services

Laonion Metrics uses YouTube API Services. By connecting it, you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What data it accesses

Only after the owner signs in with Google and grants access, and only for the owner's own channel (the tool rejects access to any other channel). It requests two read-only scopes: https://www.googleapis.com/auth/youtube.readonly and https://www.googleapis.com/auth/yt-analytics.readonly.

  • YouTube Data API v3: channel ID and name, subscriber count, total views, and the channel's uploaded videos (ID, title, publish date, duration and view count).
  • YouTube Analytics API: aggregate statistics for the channel and its videos, by day and by format (long videos or Shorts): views, watch time, average percentage viewed, and subscribers gained and lost.
  • YouTube Reporting API: the channel's daily reach report (thumbnail impressions and click-through rate). To receive it, the tool creates one reporting job for the channel; this does not change the channel or its videos.
  • An OAuth access token, so it can keep reading these statistics without asking the owner to sign in every time.

It does not access personal information about viewers: YouTube Analytics data is aggregated. It cannot upload, edit, delete or publish anything.

How the data is used

Only to show the owner's channel statistics on the owner's personal dashboard and to track the channel's progress over time. The data is not used for advertising, profiling or training AI models.

Storage and sharing

  • The data and the token are stored only on the owner's computer, in local files. They are not uploaded to any server or cloud service.
  • The data is not shared, sold or transferred to anyone. There are no third parties: no third-party analytics, advertising or content.
  • The token is never displayed or written to logs. The tool talks to Google only over HTTPS and its dashboard is reachable only from the owner's own computer.
  • Neither the tool nor these pages use cookies or similar tracking technologies.

How long the data is kept

The statistics are kept while the owner uses the tool, because the dashboard shows how the channel changes over time. The tool refreshes them several times a day with the owner's active authorization. If access is revoked or the tool stops being used, the token and all stored YouTube data are deleted from the computer within 30 days. The owner can delete them at any time.

How to revoke access

Open your Google Account's security settings at https://myaccount.google.com/permissions (also reachable at https://security.google.com/settings/security/permissions), select Laonion Metrics and remove its access. From then on the tool cannot read any data.

Google API Services User Data Policy

Laonion Metrics' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
